# K Mahesh Manickham and Co. Chartered Accountants Website

Responsive public-facing homepage for the CA office, built with plain HTML, CSS and JavaScript. No build step or framework is required.

## Files
- `index.html` — homepage structure and content
- `styles.css` — responsive green-and-white styling
- `script.js` — mobile navigation, current year and back-to-top button

## Run locally
Open `index.html` in a browser, or serve the folder with any static web server.

## GitHub Pages
In the repository, open **Settings → Pages**. Select **Deploy from a branch**, choose `main` and `/(root)`, then save. GitHub will publish the site after deployment finishes.

## Before publishing for clients
Replace the clearly-marked placeholder items in `index.html`:
- firm name / logo initials if K Mahesh Manickham and Co. is not the final public name
- office telephone number and email address
- official office address
- WhatsApp number and client portal URL
- careers destination and social profile links

The hero uses a remote Unsplash image. Replace it with an approved office/team photograph when available.

## Planned next phase
ERP is intentionally not part of this public website yet. Before implementing it, define roles and permissions, authentication, data storage, audit logs, backups, document access and deployment/security requirements. Avoid storing client tax and identity documents in a public static repository.
